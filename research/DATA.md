Paths below are relative to a private run directory unless they start with `synthetic_demo/`. Keep raw inputs and row-level outputs outside the repository. Each source is analyzed separately. Obtain the original file bytes and retain attribution and any access terms. A source landing page can be public even when file access or reuse remains unresolved. The original copies used for the November replay were already available to the project, and the run record specifies which preparation steps were verified.
